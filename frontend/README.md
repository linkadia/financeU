# Finanu Frontend

React + Vite + MUI mobile-first frontend.

## Desarrollo en red local

1. Copia `.env.example` a `.env`.
2. Cambia `192.168.0.192` por la IPv4 de tu ordenador si ha cambiado.
3. Arranca Vite exponiendo la app en la red local:

```bash
npm run dev -- --host 0.0.0.0
```

En el móvil abre la URL `Network` que muestra Vite, por ejemplo:

```text
http://192.168.0.192:5173
```
